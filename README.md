# MECH 564 Robot Mechanics and Control Labs

This repository contains the lab materials for **MECH 564: Fundamentals of Robot Mechanics and Control** at Colorado State University. It hosts the course notebook labs, supporting figures, and the published Jupyter Book website.

## 📚 View the Book

**Access the published book online**: [MECH 564 Lab Materials](https://jianguozhaorobotics.github.io/RobotMechanicsControl/)

The site is automatically built and deployed using GitHub Actions whenever changes are pushed to the main branch.

## Course Information

- **Course:** MECH 564 Fundamentals of Robot Mechanics and Control
- **Institution:** Colorado State University
- **Instructor:** Jianguo Zhao

## Contents
- `Lab1 Intro to Python.ipynb` - Python basics and setup
- `Lab2 ForwardKinematics.ipynb` - forward kinematics
- `Lab3 Inverse Kinematics & Dynamics.ipynb` - inverse kinematics and dynamics
- `Lab4_RobotControl.ipynb` - robot control
- `Lab5 quadruped_trot_demo.ipynb` - quadruped trot demonstration
